# Intent and outcome

This is a reusable method, not a project-specific state.

- Define the actual result from the user's perspective, distinguishing desired outcome, constraints and possible implementation choices.
- Separate verified facts from inference and open assumptions. Discover checkable facts independently before asking the user.
- For substantial work, examine the intended real usage path early; do not claim complete understanding while a material architectural assumption is unresolved.
- Avoid both unnecessary questions and silent changes to the explicitly requested platform, interface, deployment path or product behavior.
