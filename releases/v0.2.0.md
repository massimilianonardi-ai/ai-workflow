# AI-Workflow v0.2.0 — experimental alpha

**Release type:** pre-release (alpha).  
**Repository:** `massimilianonardi-ai/ai-workflow`.  
**Source:** promoted from `dev` to `main`.  
**State store:** `massimilianonardi-ai/ai-work-state/dev`, separately maintained; no state data promoted to its `main`.

## Included

- Three-section mandatory bootstrap with universal finalization.
- Lean, open-set MDM (`operation`, `input`, `output`, `effects`).
- `system-design` pilot with `specification`, `architecture`, optional composite `iterative-design`, and approved P1–P5 revision rules.
- Progressive continuity controller, meaningful audit log conventions and user-initiated `!aw audit`.
- `!aw route` remains a non-executing diagnostic.
- Conversation identity and an experimental Git checkpoint protocol with read-back and pending-state handling.
- Documentation for manually opting a dedicated ChatGPT Project into this alpha.

## Tests and limitations

- **7/7 static contract checks** passed based on verified repository content.
- **6/6 synthetic fixture checks** passed for Git state files. A stale-head write was not applied, but returned a generic connector error, so complete concurrency recovery is not certified.
- **Not verified:** full ChatGPT runtime behavior, real cross-chat persistence, automatic finalization, live user-audit outcomes or multiple-writer fault handling.
- **No native host feature is installed** by this release; connected GitHub permissions and explicit host setup remain essential.
- Do not infer approval for production deployment from architecture design or from the release itself.

See `README.md`, `bootstrap.md`, `deploy/chatgpt-project-instructions.md`, and `evaluations/alpha-dev-state-integration-2026-11-10.md` for details.

The version tag is intended to be immutable; the GitHub Release is created as a pre-release because the current alpha has not passed full live behavioral tests.
