# AI-Workflow v0.2.1 — alpha maintenance release

**Type:** prerelease (alpha). **Source:** `ai-workflow/main`. **Scope:** corrections to documentation, references and contract tests; no new runtime capabilities.

## Corrections

- The universal bootstrap now consistently uses macrosections **A → B → C**, including the invariant, installation instructions and identity document.
- Active references to the renamed protocol point to `state/protocol.md`; the removed `state/alpha-protocol.md` is not used.
- README and relevant module headings display the corrective release version.
- Regression tests validate the renamed sections, references and release link; GitHub Actions checks them on subsequent changes.

## Boundaries

The original `v0.2.0` release and tag remain unchanged. `ai-workflow/dev` remains a historical staging snapshot; its separate dev-installation guide correctly refers to that branch. `ai-work-state` remains unchanged, and live host-level auditing, automatic checkpoint persistence, concurrency recovery and cross-chat continuity remain unverified.
